# AI Semiconductor Monitor

An A-share AI and semiconductor research monitor focused on:

- observation universe management
- realtime market snapshots
- sector and leader analysis
- keyword-based news classification
- alerting and reports

## Quick start

1. Create and activate a Python 3.11+ virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run the demo with `python -m app.main`.

## Phase one scope

- project skeleton
- static stock universe
- placeholder data and analysis interfaces
- console-based demo output
